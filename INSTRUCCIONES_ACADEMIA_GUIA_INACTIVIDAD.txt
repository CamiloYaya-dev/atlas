ATLAS V4.8.1 — PARCHE: ASISTENCIA CONTEXTUAL + CAMPOS DEL INSPECTOR
====================================================================

PARCHE RECOMENDADO (SIN PERDER DATOS):
1. Haz copia de seguridad de tu carpeta C:\Users\MSI1\Desktop\atlas.
2. Descomprime el parche DIRECTAMENTE dentro de esa carpeta; sobrescribe los archivos.
   El parche contiene rutas apps/web/... y docs/..., sin carpeta atlas/ superior.
3. Conserva .env, node_modules, Docker y tu base de datos PostgreSQL.
4. En PowerShell, ejecuta por separado:
   npm run typecheck
   npm run test:ui
   npm run build
5. Abre «Misiones». En el pie, elige 1, 2, 3 minutos o «Desactivado».
6. Para comprobar la guía: deja ATLAS sin actividad el tiempo elegido. El paso pendiente
   tendrá un borde animado. Si está fuera de vista, el pie ofrecerá «Sube»/«Baja».
   Desplazar el panel a mano oculta la flecha cuando el paso es visible.
7. Abre «Configurar campo» y «Abrir Inspector» dentro de las nuevas tareas para
   completar los requisitos funcionales y técnicos, y espera a «Guardado».
