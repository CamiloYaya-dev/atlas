ATLAS V4.8.1 — PARCHE DE RELACIONES, NAVEGACION PRECISA Y ACADEMIA
==================================================================

RECOMENDADO: USA EL PARCHE SI YA TIENES LA ULTIMA VERSION DE ACADEMIA.

1. Cierra ATLAS y realiza backup de C:\Users\MSI1\Desktop\atlas.
   Haz además una exportación JSON del proyecto de práctica.
2. Extrae el ZIP del parche DIRECTAMENTE dentro de C:\Users\MSI1\Desktop\atlas.
   Sobrescribe los archivos cuando Windows te lo solicite.
3. Conserva archivos .env, node_modules, bases PostgreSQL y volúmenes Docker.
   NO ELIMINES LOS DATOS EXISTENTES. No se requieren migraciones.
4. Ejecuta, por separado, dentro de PowerShell:
   npm run typecheck
   npm run test:graph
   npm run test:ui
   npm run test:unit
   npm run build
5. Reinicia el frontend; recarga el navegador con Ctrl+F5.
6. Abre una relación y comprueba el botón de eliminación con confirmación,
   las flechas bidireccionales, tres puertos arriba y abajo, y el tipo de línea.
7. En el Inspector elige Vista vinculada y Caja de destino, haz doble clic,
   verifica enfoque en esa caja y la acción Volver.
8. En el laboratorio técnico, C2 admite las conexiones correctas en ambos
   sentidos. En el ejercicio de campos, pulsa «Muéstrame dónde» y busca
   el botón de Configurar que ATLAS resalta en el Inspector.

ALCANCE DE PRUEBAS EN EL ENTORNO DE GENERACION:
  npm run typecheck: PASS (API + WEB)
  npm run test:graph: 15/15 PASS
  npm run test:qa-tools: 4/4 PASS
  Vitest / E2E / build final: pendientes en Windows debido a incompatibilidad
  de binarios nativos esbuild/Rollup de los node_modules disponibles aqui.
